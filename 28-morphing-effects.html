SVG 路径形变 Blob 有机形变 文字形变 液态形变按钮 粒子形变

1. SVG 路径形变

SVG SMIL + CSS — 多个几何形状之间平滑插值变形，点击切换目标形状

2. Blob 有机形变

Canvas 2D + Simplex Noise — 多个 Blob 随噪声独立演化，鼠标靠近时相互吸引融合

3. 文字形变

Canvas 2D 像素采样 — 将文字渲染为粒子点阵，粒子在不同文字之间流动变形

4. 液态形变按钮

SVG feTurbulence + feDisplacementMap — 悬停时按钮边缘产生液态蠕动变形，CSS 过渡驱动

5. 粒子形变 — 图标变换

Canvas 2D — 粒子群在多个图标形状之间流动变形，每个粒子独立弹簧物理
