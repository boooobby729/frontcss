频谱柱状 圆形频谱 波形线 粒子频谱 示波器

1. 频谱柱状可视化

Canvas 2D — 模拟 FFT 频谱数据，渐变色柱状图 + 顶部残影粒子，点击切换音乐风格

2. 圆形频谱可视化

Canvas 2D — 360° 环形频谱，内外双环镜像，中心脉冲光晕随低频跳动

3. 波形线可视化

Canvas 2D — 多层叠加波形，每层独立频率与相位，颜色随振幅动态变化

4. 粒子频谱可视化

Canvas 2D — 频谱数据驱动粒子喷射，粒子受重力与衰减影响，形成音乐喷泉效果

5. 示波器风格可视化

Canvas 2D — 模拟 CRT 示波器，绿色磷光余辉，Lissajous 图形 + 扫描线
