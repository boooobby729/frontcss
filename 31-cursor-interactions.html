2. 磁性按钮

JavaScript getBoundingClientRect — 鼠标靠近时按钮被磁力吸引，离开时弹回，配合文字跟随

3. 点击涟漪效果

Canvas 2D — 点击任意位置产生多层涟漪扩散，颜色随位置变化，支持多点同时

CLICK ANYWHERE

4. 聚光灯跟随

MOVE TO REVEAL

5. 重力场交互

Canvas 2D 物理模拟 — 鼠标产生引力/斥力场，粒子受力运动，点击切换引力/斥力
