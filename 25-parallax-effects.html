1. 3D 倾斜卡片

CSS perspective + transform — 鼠标追踪产生 3D 透视倾斜 + 动态光影 + 环境反射

Interactive Card

移动鼠标在卡片上方感受 3D 透视倾斜效果，光影跟随视角变化。

2. 深度分层视差

CSS transform + 鼠标追踪 — 多层元素按不同速率响应鼠标移动，制造空间纵深感

3. 星空穿越视差

Canvas 2D — 模拟星空纵深飞行，星体按 Z 轴分层以不同速度划过，制造超空间跃迁感

4. 滚动揭示动画

IntersectionObserver + CSS transforms — 元素在进入视口时带有淡入/滑入/缩放等动画

淡入上移

元素从下方 40px 位置淡入到原始位置。常用于内容区域的入场动画。

从左滑入

元素从左侧 60px 位置滑入到原始位置。适合时间线或列表项。

从右滑入

元素从右侧 60px 位置滑入。常用于交替排列的内容展示。

缩放出现

元素从 80% 尺寸放大到 100%，同时淡入。适合卡片和图片。

旋转进入

元素带有轻微旋转和位移，纠正到正常位置。增添趣味性。

延迟序列

滚动此区域查看所有动画效果。在实际项目中可通过 transition-delay 实现错落入场。

5. 透视网格地面

Canvas 2D + 透视投影 — 无限延伸的网格地面 + 发光线条 + 前进动画，赛博朋克风格
